Python 学习笔记：装饰器与生成器

Python 2026-09-05 · 阅读约 4 分钟

装饰器：给函数"加buff"

装饰器本质是一个接收函数、返回函数的高阶函数。比如想在每个函数调用前后打印日志，不用修改每个函数，套一层装饰器就行：

@log 等价于 add = log(add)——把原函数传进去，返回包装后的新函数。

两个易错点：① 包装函数最后一定要 return wrapper；② 记得用 @functools.wraps(func)，否则函数名会变成 wrapper。

生成器：惰性产出，省内存

普通函数用 return 返回一次就结束；生成器用 yield 可以产出多次，而且每次只在被需要时才算下一个值。

处理大文件时，for line in f: yield line 不会把整个文件读进内存，这是生成器最实用的场景。

另外生成器里的 yield 放在哪个缩进层级很重要——放在 if 里面才是"满足条件才产出"，我就因为缩进写错调试了半天 😅
