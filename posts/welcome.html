你好，世界：我的第一篇博客

随笔 2026-09-08 · 阅读约 2 分钟

就像学每门编程语言的第一个程序都是 Hello, World! 一样，这个博客的第一篇文章，也从"你好，世界"开始。

为什么写博客？

学习过程中我经常遇到一个问题：当时弄懂的知识点，过几周就忘了。把学到的东西用自己的话写出来，是最好的复习方式——能讲清楚，才算真的学会。

写博客不是为了成为专家，而是为了记录自己从不会到会的过程。

这个博客是怎么搭的？

没有使用复杂的框架，就是最朴素的三件套：

📄 HTML 负责页面结构　🎨 CSS 负责莫兰迪配色样式　⚡ JavaScript 负责文章搜索

然后把代码推送到 GitHub 仓库，开启 GitHub Pages，几分钟就拥有了一个免费的个人网站。

接下来会写什么？

Python 学习笔记、做过的小项目、踩过的坑……欢迎常来看看 🌿
