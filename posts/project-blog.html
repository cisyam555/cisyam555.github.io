项目展示：用 GitHub Pages 搭建个人博客

项目 2026-09-08 · 阅读约 3 分钟

项目简介

一个纯静态的个人博客，无需服务器、无需数据库、无需构建工具。特点：

🎨 莫兰迪低饱和配色，圆角卡片 + 柔和阴影
🔍 首页支持文章标题/标签实时搜索
📱 响应式布局，手机上也能正常阅读
🆓 托管在 GitHub Pages，完全免费

技术栈

HTML5 + CSS3（CSS 变量管理配色）+ 原生 JavaScript（搜索过滤）

部署方式

在 GitHub 新建名为 用户名.github.io 的仓库，把文件推送到 main 分支，在 Settings → Pages 里选择分支，等待一两分钟即可访问。

最大的收获：原来不依赖框架也能做出好看的网站，把基础的 HTML/CSS 学扎实很重要。
