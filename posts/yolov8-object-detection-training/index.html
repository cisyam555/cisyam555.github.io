YOLOv8 目标检测实战：从环境搭建到模型训练

# YOLOv8# 目标检测# PyTorch# 深度学习# 学习笔记

一、前言

随着人工智能技术的发展，计算机视觉已经广泛应用于目标检测、图像分类、自动驾驶和智能安防等领域。目标检测是计算机视觉中的重要任务之一，它不仅需要识别图片中的物体，还需要确定物体在图片中的位置。

YOLO 是一种常见的目标检测算法。与传统的目标检测方法相比，YOLO 将目标位置预测和类别识别整合到一个模型中，能够较高效地完成目标检测任务。

本文主要记录我学习 YOLOv8 的过程，包括目标检测基础知识、开发环境搭建、模型预测、数据集准备、模型训练和结果分析，并通过 dog-breed-detection 项目进行实践。

通过这次学习，我希望逐步掌握 YOLOv8 的基本使用方法，理解目标检测模型从数据准备到训练验证的完整流程。

二、YOLOv8 简介

YOLOv8 是 Ultralytics 推出的计算机视觉模型系列，支持目标检测、图像分类、实例分割、姿态估计等任务。

本文主要学习 YOLOv8 的目标检测功能。目标检测主要解决两个问题：

  1. 图片中有什么物体？
  2. 物体在图片的什么位置？

例如，给模型输入一张包含狗的图片，模型可以预测狗所在的检测框，并输出相应的类别和置信度。

目标检测的主要输出包括：

  • 类别（Class）：模型识别出的物体类别。
  • 检测框（Bounding Box）：物体在图片中的位置。
  • 置信度（Confidence）：模型对检测结果的置信程度。

需要注意，置信度并不代表模型一定正确，模型的实际性能还需要结合验证集和其他评价指标进行分析。

三、开发环境搭建

本次学习使用 Ubuntu 24.04 作为开发环境，主要使用 Python、PyTorch 和 Ultralytics 提供的 YOLOv8 接口。

3.1 检查 Python 环境

首先打开终端，查看 Python 版本：

python3 --version

再检查 pip 是否可用：

python3 -m pip --version

建议为项目创建独立的 Python 虚拟环境，避免不同项目之间的依赖发生冲突。

3.2 创建虚拟环境

python3 -m venv .venv
source .venv/bin/activate

激活环境后，可以使用下面的命令检查 Python 路径：

which python

如果输出路径指向当前项目的 .venv 目录，说明虚拟环境已经生效。

3.3 安装 YOLOv8

在虚拟环境中安装 Ultralytics：

python -m pip install --upgrade pip
python -m pip install ultralytics

安装完成后，检查是否可以正常导入：

python -c "from ultralytics import YOLO; print('YOLO 安装成功')"

如果没有出现报错，就可以继续进行后续实验。

需要说明的是，PyTorch 是否使用 GPU，取决于显卡型号、驱动和对应的 PyTorch 安装配置。安装成功并不意味着 GPU 一定已经启用。

四、使用 YOLOv8 进行目标检测

完成环境搭建后，可以先使用预训练模型进行图片预测，了解 YOLOv8 的基本工作流程。

4.1 编写预测代码

新建一个 Python 文件，例如 predict.py：

from ultralytics import YOLO
​
# 加载预训练模型
model = YOLO("yolov8n.pt")
​
# 对图片进行预测
results = model.predict(
    source="test.jpg",
    save=True,
    conf=0.25
)
​
print("预测完成")

其中：

  • yolov8n.pt 是 YOLOv8 Nano 模型的预训练权重。
  • source 指定需要检测的图片。
  • save=True 表示保存带有检测结果的图片。
  • conf=0.25 表示设置置信度阈值为 0.25。

运行代码前，需要准备一张名为 test.jpg 的图片，并将它放在当前工作目录中。

运行命令：

python predict.py

默认情况下，预测结果通常保存在 runs/detect/predict/ 等输出目录中。如果目录已经存在，Ultralytics 可能会自动使用带编号的目录。

通过这一步，可以初步了解模型如何读取图片、生成检测结果并保存可视化图片。

五、数据集准备与标注

如果希望训练一个能够识别特定类别的模型，就需要准备与任务对应的数据集。

目标检测数据集通常包含图片文件和标注文件。每张图片中的目标需要标注类别以及目标的位置。

5.1 YOLO 标注格式

YOLO 检测任务通常使用以下格式记录每个目标：

class_id x_center y_center width height

其中：

  • class_id：类别编号。
  • x_center：检测框中心点的横坐标。
  • y_center：检测框中心点的纵坐标。
  • width：检测框宽度。
  • height：检测框高度。

坐标和宽高通常按照图片的宽度和高度进行归一化，因此数值一般在 0 到 1 之间。

例如：

0 0.50 0.50 0.40 0.60

这表示一个类别编号为 0 的目标，其检测框中心位于图片中央附近，宽度约为图片宽度的 40%，高度约为图片高度的 60%。

5.2 划分数据集

为了评估模型的泛化能力，通常需要将数据集划分为训练集、验证集和测试集。

  • 训练集：用于模型训练。
  • 验证集：用于训练过程中的性能评估和模型选择。
  • 测试集：用于最终评估模型在未参与训练和模型选择的数据上的表现。

划分数据集时，应尽量避免高度重复的图片同时出现在训练集和测试集中，否则评估结果可能过于乐观。

六、YOLOv8 模型训练

准备好数据集后，就可以使用 YOLOv8 进行训练。

6.1 配置 data.yaml

目标检测数据集通常需要一个 YAML 配置文件，用于指定数据集路径和类别信息。

例如：

path: ./dataset
train: images/train
val: images/val
​
names:
  0: dog
  1: cat

这里的 dog 和 cat 仅用于说明配置格式，实际使用时应根据自己的数据集修改类别名称和编号。

数据集目录可以采用如下结构：

dataset/
├── images/
│   ├── train/
│   └── val/
└── labels/
    ├── train/
    └── val/

每张图片应有对应的 YOLO 格式标签文件。标签文件名通常与图片文件名一致，只是扩展名不同。

6.2 编写训练代码

新建 train.py：

from ultralytics import YOLO
​
# 加载预训练模型
model = YOLO("yolov8n.pt")
​
# 开始训练
results = model.train(
    data="dataset/data.yaml",
    epochs=50,
    imgsz=640,
    batch=16,
    project="runs/my_project",
    name="yolov8n"
)
​
print("训练完成")

主要参数说明：

  • data：数据集配置文件路径。
  • epochs：训练轮数。
  • imgsz：训练图像尺寸。
  • batch：每批次处理的图片数量。
  • project：实验结果的保存目录。
  • name：本次实验的名称。

以上参数只是示例，实际训练时需要根据数据集大小、显存容量和实验目标调整。如果出现显存不足，可以尝试减小 batch。

6.3 理解训练结果

训练完成后，Ultralytics 通常会保存模型权重、训练参数、评价指标和相关可视化结果。

常见文件包括：

  • best.pt：训练过程中验证表现较好的模型权重。
  • last.pt：最后一个训练轮次对应的模型权重。
  • results.csv：各轮训练和验证指标的记录。
  • results.png：训练过程中的指标变化曲线。

这些文件可以帮助我们分析模型是否逐步收敛，以及训练过程中的性能变化。

需要注意，训练损失下降并不一定意味着模型在新图片上的检测效果一定更好，因此还需要结合验证指标和实际预测结果进行分析。

七、模型验证与评价指标

训练结束后，需要验证模型的检测效果，而不能只看训练是否成功。

YOLOv8 目标检测中常见的评价指标包括 Precision、Recall 和 mAP。

7.1 Precision（精确率）

精确率表示模型预测为正例的结果中，实际正确的比例。

当误检较多时，精确率通常会受到影响。

7.2 Recall（召回率）

召回率表示实际存在的目标中，被模型成功检测出来的比例。

当漏检较多时，召回率通常会受到影响。

7.3 mAP（平均精度均值）

mAP 是目标检测任务中常用的综合评价指标，考虑不同类别的检测性能以及相应的精度评价方式。

常见的指标包括 mAP50 和 mAP50-95。后者会在多个 IoU 阈值下进行评价，通常比单独的 mAP50 更严格。

可以使用以下代码验证模型：

from ultralytics import YOLO
​
model = YOLO("runs/my_project/yolov8n/weights/best.pt")
​
metrics = model.val(data="dataset/data.yaml")
​
print(metrics)

其中模型路径和数据集路径需要根据实际项目目录修改。

在分析结果时，除了查看评价指标，还应观察预测图片，检查模型是否存在误检、漏检或者检测框定位不准确等问题。

八、dog-breed-detection 项目实践

为了进一步理解 YOLOv8 的实际应用，我继续学习了 dog-breed-detection 项目。

这个项目可以作为综合练习，帮助理解从数据集处理到模型训练的完整流程。

主要学习内容包括：

  1. 认识项目的目录结构。
  2. 理解原始数据和标注文件的组织方式。
  3. 学习将 XML 标注转换为 YOLO 格式。
  4. 划分训练集和验证集。
  5. 配置数据集并训练模型。
  6. 使用验证集评估模型。
  7. 查看训练曲线和预测结果。
  8. 分析训练过程中出现的问题。

如果项目使用 XML 标注文件，就需要先弄清楚 XML 中记录的类别和边界框信息，再按照 YOLO 的归一化坐标格式进行转换。

在这个过程中，我可以进一步理解数据预处理、模型训练、指标评估之间的关系，并熟悉一个完整目标检测项目的基本工作流程。

项目中具体使用的数据集、类别数量、训练参数和实验结果，应以实际代码和运行记录为准。

这次学习让我认识到，目标检测不仅需要理解模型本身，还需要重视数据集质量、标签格式、训练参数和评价指标。
